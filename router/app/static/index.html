Nigerian News Router Prototype / v0.1

A proposal — prototype, working now

The same story, from every newsroom at once.

When something happens in Nigeria, a dozen newsrooms report it and nobody can see them together. This indexes — reports from — newsrooms under one set of field names, and it is running below. Search it.

Who is in the index

The newsrooms the router knows about. A filled dot means it is being indexed today; the rest are known to the router but not read from.

Why it is worth doing

Six things this makes possible that no single newsroom's own feed can.

One story, every version of it

The same event is reported by Punch, Vanguard and Premium Times within minutes of each other, and today there is no way to line those up. This returns them together, each linked back to the newsroom that filed it.

One address, many newsrooms

Anyone building on Nigerian reporting integrates each outlet separately and repairs it after every redesign. Field names and date formats are fixed here, so adding a newsroom changes nothing for the caller.

Permission is enforced per report

A single answer mixes newsrooms on different agreements, so what each one permits is applied to its own reports as they are served. Anything outside a newsroom's grant comes back empty and says so.

Corrections travel

Changes are caught by comparing the report itself, so a quiet edit is noticed even when the CMS timestamp never moves. Every version is kept, with the fields that changed named.

Only the front of the story leaves

Headline, standfirst, byline, time, section, a short extract and the thumbnail. The body of a report is read while indexing and then discarded. It is never stored and never served, at any tier.

There is nothing new to run

For most newsrooms this reads the feed the site already publishes. No second copy of the archive, no software to install, and it cannot change or remove a single report.

Show the developer view

Read-only endpoints, every one of them runnable here against the live index, with the response shown exactly as a client receives it. Anonymous callers get 30 requests a minute; issued keys get their own limit.

GET /v1/search

Full text across every indexed newsroom at once — headline, standfirst, extract and the tags the newsroom applied.

qrequired, your search terms
sourcenarrow to one or more newsrooms, comma separated
limit1–100, default 25
/v1/search?q=fake%20agency

GET /v1/articles

Every indexed report, newest first, across all newsrooms. Advertorial is excluded unless asked for.

sourcenewsroom ids, comma separated
sectiondesk or beat
languageen, ha, yo, pcm
wire_sourcee.g. NAN — or none for a newsroom's own reporting
since / untilISO timestamp, UTC
include_sponsoreddefault false
limit / cursor1–100, default 25; cursor from the previous page
/v1/articles?limit=3

GET /v1/articles/{id}/revisions

Every version of one report that the router has seen, and which fields moved between them. This is how a correction reaches a partner.

idrequired, e.g. premium-times:904543
/v1/articles/…/revisions

GET /v1/sources

Every newsroom the router knows about, how it is read, and exactly what it has permitted.

/v1/sources

GET /v1/clusters

The same story grouped across newsrooms. The schema and endpoint are in place; the matching that fills them is not built yet, so this returns empty.

/v1/clusters

Index size and whether any newsroom is failing to read.
